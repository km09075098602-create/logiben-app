# ロジ弁 お弁当注文・管理アプリ(試作版)

松江市の会社向けお弁当食事補助サービス「ロジ弁」(運営:達磨商事、2027年1月開始予定)の注文・管理アプリです。

## いまできること(試作 v0.5)

| 画面 | できること |
|---|---|
| ログイン(`/`) | 社員:会社コード+社員番号 / 会社の担当者:会社コード+ログインID / お店:ログインID / 管理者:ログインID(どれもパスワードつき) |
| 会社の担当者の画面(`/company.html`) | 自社の月ごとの請求額・食数・利用人数、ご利用明細(印刷可)、社員ごとの内訳(CSV保存可)、日ごとの注文一覧。**自社の分しか見られません** |
| お店の画面(`/shop.html`) | **注文**:日ごとの注文数(締め切り前は「受付中」、後は「確定」)、お弁当ごとの数、お届け先(会社・部署)ごとの中身(印刷可)<br>**メニュー**:自分のお店のメニューの追加・値段や説明の変更・販売停止<br>**お支払い**:2週間ごとのお支払い明細。**自分のお店の分しか見られません** |
| 社員の注文画面(`/order.html`、スマホ向け) | 日付を選んでお弁当を注文・変更・取り消し(締め切りまで)。お弁当ごとに「あなたの支払い額」を表示。今月の会社負担の使用状況をメーターで表示し、上限の80%を超えたら注意、上限に達したら全額自己負担になることをお知らせ |
| 管理者画面(`/admin.html`) | 日付ごとの注文数、お店ごと・お弁当ごとの数と金額、会社・部署順の注文一覧(印刷可)。締め切り時刻などの**設定の変更** |
| 登録画面(`/manage.html`、管理者) | **お店とメニュー**:お店の追加・名前変更・停止、メニューの追加・値段や説明の変更・販売停止、お店のログイン用アカウント<br>**会社と社員**:担当者のアカウント、会社の追加・変更・停止、社員の追加(1人ずつ / CSVでまとめて)・変更・停止、パスワードの再発行。初期パスワードは自動で作られ、CSVで保存して社員に配れます |
| 印刷画面(`/print.html`、管理者) | **名前シール**:A4ラベル用紙に「会社名・名前・部署・お弁当・日付とお店」を印刷。用紙の種類、何枚目から印刷するか、位置の微調整、試し刷り用の枠線。<br>**配達表**:会社ごとに1ページ。お弁当ごとの数、部署ごとの名前一覧(受け取りチェック欄つき)。<br>どちらも日付・お店・会社で絞り込みできます |
| 請求画面(`/billing.html`、管理者) | **会社への請求(月ごと)**:会社ごとの食数・会社負担分・利用料・消費税・請求額、社員ごとの内訳。会社ごとの明細を印刷できる<br>**お店への支払い(2週間ごと)**:お店ごとのお弁当代・営業代行料・支払額、お弁当ごとの数。お店ごとの明細を印刷できる<br>**CSV保存**:注文の明細 / 会社ごとの請求 / 社員ごとの内訳(月ごと)、お店への支払い(期間ごと) |

#### 名前シールの印刷のコツ
- 印刷するときは、ブラウザの印刷画面で「倍率:100%(実際のサイズ)」「余白:なし」にする
- 初めて使う用紙では、「ラベルの枠を印刷する」をオンにして普通の紙に試し刷りし、ラベル用紙に重ねて位置を確認する。ずれていたら「位置の微調整」で直す(設定はそのパソコンに記憶される)
- 用紙の寸法は `public/labels.js` にまとめてある。使う用紙が決まったら、パッケージの寸法に合わせて直すか追加する

#### 請求・支払いの計算(仮決め・`src/billing.js`)
- **会社への請求** = 会社負担分(お弁当代の半額の合計・税込・上限あり)+ サービス利用料(150円 × 食数・税抜)+ 利用料の消費税10%
  - 利用料は、会社負担の上限に達したあとの食事にもかかる
  - 社員負担分の合計も「参考」として出す(給料から差し引く場合などに使う)
  - 明細には税率ごとの合計と消費税額も出す(8%対象 / 10%対象)
- **お店への支払い** = お弁当代(税込)の合計 − 営業代行料(合計の10%・税込・1円未満切り捨て)
  - 「2週間」の区切りは、設定の「起点日」(初期値 2027-01-04 月曜)から14日ずつ
- 月や期間が終わる前に開くと「途中経過」と表示される

#### 登録画面の約束ごと
- 削除はせず「停止」にします(過去の注文・請求の記録を残すため)。再開もできます
- メニューの値段を変えても、すでに入っている注文の値段は変わりません(注文時の値段を記録)
- 社員を停止すると、ログインできなくなり、明日以降の注文は取り消されます
- 会社を停止すると、その会社の社員は全員ログインできなくなります
- 社員の一括登録(CSV)は「社員番号, 名前, 部署」の3列。Excel で保存した CSV(Shift_JIS)もそのまま読めます。1人でも間違いがあれば、全員分を登録せずに間違いの行を知らせます

## お金のルール(仮決め)

ルールはすべて `src/rules.js` にまとめてあり、`tests/rules.test.js` の自動テストで確かめています。

- お店はメニューを**税込み価格**で登録する
- 1食ごとに会社が半額を負担する。1円未満の端数は社員の負担
- 会社負担の上限は1人あたり月7,500円(税抜き)。税込みに直すと8,100円(軽減税率8%)
- 上限をまたぐ注文は、会社が残り分だけを負担し、残りは社員の負担。その後のお弁当は社員が全額を負担する
- 上限はお届け日の早い順に使っていく。前の日の注文を取り消すと、あとの日の負担額は自動で計算し直す
- 上限の80%を超えたら社員の画面にお知らせを出す
- 締め切りは、初期設定では当日9:30。管理画面で前日締めに変えたり、時刻を変えたりできる。土日は注文できない

上限・税率・利用料・代行料などの数値は、管理画面の「設定」から変えられます。

## しくみ

```
public/        画面(HTML・デザイン・画面の動き)
src/index.js   サーバー本体(ログイン・注文・集計の窓口=API)
src/master.js  登録画面のAPI(お店・メニュー・会社・社員)
src/billing.js 請求・支払いの計算
src/billing-routes.js 請求・支払い・CSVのAPI
src/portal-routes.js 会社の担当者・お店の画面のAPI
src/queries.js 注文データの取り出し(共通)
public/labels.js ラベル用紙の寸法
src/rules.js   お金と締め切りのルール
src/password.js パスワードの安全な保存
db/schema.sql  データベースの形
scripts/make-seed.mjs  試作用の仮データを作る
tests/         自動テスト
```

使っている道具:Cloudflare Workers(サーバー)+ D1(データベース)+ Hono(サーバーの部品)。
費用は、試作中は0円です。本番で利用が増えても、月5ドル(約800円)程度の見込みです。

## 自分のパソコンで動かす

Node.js(バージョン20以上)が必要です。

```bash
npm install        # 部品のインストール(最初の1回)
npm run db:reset   # データベースを作り、仮データを入れる(何度でもやり直せる)
npm run dev        # http://localhost:8787 で起動
npm test           # お金・締め切りのルールの自動テスト
```

## インターネットに公開する(Cloudflare・無料)

1. https://dash.cloudflare.com/sign-up で Cloudflare のアカウントを作る(無料)
2. `npx wrangler login` を実行し、ブラウザでログインする
3. `npx wrangler d1 create logiben` を実行し、表示された `database_id` を `wrangler.toml` に貼る
4. `npx wrangler d1 execute logiben --remote --file=db/schema.sql` でデータベースを作る
   (お試しデータを入れる場合は、続けて `--file=db/seed.sql` も実行する)
5. `npm run deploy` を実行すると、`https://logiben.(あなたのID).workers.dev` で公開される

※ 本番で使う前に、仮データの管理者パスワードは必ず変えてください。
